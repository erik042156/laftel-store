### 결함 의심 상세 (사용자 확인 완료, 2026-09-04)

**[DEFECT-SEARCH-001] 와일드카드성 특수문자("?", "*") 입력 시 결과 없음 화면 미노출 (TC-SEARCH-028, TC-SEARCH-029 공통 이슈)**

- **관련 TC**: TC-SEARCH-028("?"), TC-SEARCH-029("*") — 두 문자 모두 동일한 패턴의 이상 동작을 보여 하나의 결함 이슈로 통합해 서술한다. TC 자체는 특수문자별 재현 조건이 달라 2건으로 유지한다.
- **근본 원인(추정)**: "?"와 "*"를 입력했을 때 모두 결과 없음 화면 대신 가나다순으로 정렬된 것으로 보이는 전체 작품 목록(최대 20개)과 연관 검색어로 보이는 상품명 텍스트(최대 10개)가 동일한 패턴으로 노출됨. 두 문자 모두 일반적으로 와일드카드로 쓰이는 특수문자라는 공통점이 있어, 검색 로직에서 이 문자들을 와일드카드처럼 처리해 전체 결과를 반환하는 동일한 원인에 의한 것으로 추정한다(코드 확인 전까지는 추정이며 확정 아님).
- **관찰된 실제 동작(Actual, Fail 추적용 참고 정보)**:
  - "?" 입력: 결과 없음 화면 대신 전체 작품 목록(최대 20개)과 연관 검색어(최대 10개)가 노출된다. URL은 `/search?keyword=%3F`로 표시되며, `%3F`는 "?"의 정상적인 percent-encoding이므로 이는 결함이 아니다(사용자 확인 완료 — 이전 초안에서 URL 인코딩 불일치로 잘못 기록했던 부분을 정정함).
  - "*" 입력: 결과 없음 화면 대신 전체 작품 목록(최대 20개)과 연관 검색어(최대 10개)가 노출된다.
- **PRD 기준 기대 동작 대비**: REQ-SEARCH-017에 따르면 매핑되는 자동완성/작품이 없는 입력은 결과 없음 화면이 노출되어야 하나, 실제로는 전체 목록이 노출되어 기준과 불일치한다(위 표의 Expected Result 대비 Fail로 추적 대상).
