## Priority 산정 근거

- **TC-CART-001, 002, 003, 004, 005, 006, 010, 011, 018, 019, 020, 021, 022 (진입/레이아웃 노출/단순 삭제 흐름/빈 상태)**: Impact 2~3 / Likelihood 2 / Risk Score 4~6 — 정적 정보 노출이거나, 확인 팝업을 거치는 삭제 흐름이라 실수로 인한 데이터 손실 가능성이 낮음.
- **TC-CART-007, 008 (배송비 문구 조건 분기)**: Impact 3 / Likelihood 3 / Risk Score 9 — 선택 건수에 따라 문구가 달라지는 조건 분기이며, 결제금액에 대한 사용자 신뢰와 연결되어 오표시 시 혼란을 줄 수 있음.
- **TC-CART-009 (결제금액 섹션)**: Impact 4 / Likelihood 3 / Risk Score 12 — 여러 항목(상품금액/배송비/할인)이 합산되는 금액 정보로, 오류 시 신뢰성에 직접 영향.
- **TC-CART-012, 013, 014 (개별/그룹/전체 선택 동작)**: Impact 3 / Likelihood 3 / Risk Score 9 — 3단계 선택 상태(개별/그룹/전체)가 서로 연동되어야 하는 로직으로 결함 가능성이 일반 수준 이상이며, 선택 상태는 결제금액 계산에 직접 영향을 줌.
- **TC-CART-015 (수량 조절에 따른 실시간 금액 갱신)**: Impact 4 / Likelihood 3 / Risk Score 12 — 결제금액 계산 정확성과 직결되는 핵심 로직으로, 오류 시 잘못된 금액으로 결제가 진행될 위험이 있음.
- **TC-CART-016 (최소 수량 경계)**: Impact 3 / Likelihood 3 / Risk Score 9 — 경계값 처리 실패 시 수량이 0 이하로 내려가거나 의도치 않은 삭제 팝업이 뜰 수 있는 리스크가 있음.
- **TC-CART-017 (재고 상한 경계)**: Impact 3 / Likelihood 3 / Risk Score 9 — 재고 데이터와 연동된 경계 처리로, 실패 시 실제 재고보다 많은 수량으로 주문이 진행될 위험이 있음.
- **TC-CART-023 (선택 0건 상태 구매하기 클릭 가드)**: Impact 2 / Likelihood 2 / Risk Score 4 — 안내 팝업 노출 후 "확인" 클릭 시 장바구니 화면이 그대로 유지되는 단순 가드 로직으로, 데이터 변경이나 결제 진행이 발생하지 않아 영향 범위가 제한적임. 버튼 클릭 시 확인 팝업을 거치는 기존 유사 TC(TC-CART-018~021)와 동일한 Priority 수준으로 평가.
