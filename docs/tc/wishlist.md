## Priority 산정 근거

- **TC-WISHLIST-001, 002, 003 (메인페이지 찜 핵심 동작: 로그인유도/추가/해제)**: Impact 4 / Likelihood 3 / Risk Score 12 — 찜은 여러 화면에서 공통으로 쓰이는 핵심 개인화 기능이며, 로그인 여부·토글 상태에 따른 분기 로직이 있어 결함 가능성이 일반 수준 이상.
- **TC-WISHLIST-004, 005 (검색/작품페이지 진입점 동일 동작 재확인)**: Impact 3 / Likelihood 2 / Risk Score 6 — 핵심 찜 로직 자체는 001~003에서 이미 검증되며, 다른 진입점에서의 재확인은 추가 리스크가 상대적으로 낮음.
- **TC-WISHLIST-006 (찜 메뉴 뱃지 즉시 갱신)**: Impact 3 / Likelihood 3 / Risk Score 9 — 실시간 동기화 로직이 필요해 결함 가능성이 있음.
- **TC-WISHLIST-007 (찜한 상품 섹션 노출)**: Impact 2 / Likelihood 2 / Risk Score 4 — 단순 목록 표시.
- **TC-WISHLIST-008 (최근 본 상품 하트 색상+상태 뱃지 구분)**: Impact 4 / Likelihood 3 / Risk Score 12 — 찜 여부와 상품 상태 뱃지라는 두 조건이 결합된 표시 로직으로 결함 가능성이 일반 수준 이상이며, 잘못 표시되면 사용자가 찜 상태를 오인할 수 있음.
- **TC-WISHLIST-009 (여러 화면 간 실시간 동기화)**: Impact 4 / Likelihood 4 / Risk Score 16 → P0 — "최근 본 상품", "찜한 상품", `/my/wish` 세 화면 간 데이터 정합성이 요구되는 구조적으로 복잡한 동기화 로직이며, 실패 시 사용자에게 혼란을 주는 데이터 불일치로 이어짐.
- **TC-WISHLIST-010, 012, 013, 014, 017, 018, 019, 020, 021, 022, 023, 025, 026, 027, 030 (탭/레이아웃/편집 UI 노출 및 단순 조작)**: Impact 2~3 / Likelihood 2 / Risk Score 4~6 — 대부분 정적 구성 확인 또는 단순 토글/이동 동작으로 영향이 제한적.
- **TC-WISHLIST-011 (무한 스크롤)**: Impact 3 / Likelihood 3 / Risk Score 9 — 스크롤 기반 추가 로딩 로직으로 결함 가능성이 일반 수준 이상.
- **TC-WISHLIST-015, 016 (작품 자체 찜 해제/개별 상품 해제+동기화)**: Impact 4 / Likelihood 3 / Risk Score 12 — 작품(IP) 자체의 찜 상태와 개별 상품 찜 상태라는 서로 다른 두 데이터를 함께 다루는 로직이며(2026-09-06 실측으로 섹션 하트는 다건 상품을 일괄 삭제하지 않고 작품 자체 찜만 토글함을 확인), 두 상태 간 혼동이나 동기화 오류 시 사용자가 찜 데이터를 오인할 수 있어 영향이 큼.
- **TC-WISHLIST-024 (선택삭제 확정, 데이터 영구 삭제)**: Impact 5 / Likelihood 3 / Risk Score 15 → P1 — 확인 팝업을 거치지만 실제로 사용자 찜 데이터를 되돌릴 수 없게 삭제하는 동작이라 Impact를 높게 평가.
- **TC-WISHLIST-028, 029 (로그인 유도 팝업 취소 시 진입 경로별 분기)**: Impact 4 / Likelihood 3 / Risk Score 12 — 진입 경로에 따라 다른 동작을 해야 하는 조건 분기이며, 오동작 시 사용자가 의도치 않은 페이지로 이동해 혼란을 줄 수 있음.
- **TC-WISHLIST-031, 032 (로그인 완료 후 리디렉션 분기)**: Impact 4 / Likelihood 4 / Risk Score 16 → P0 — 외부 로그인 플로우와 연동되는 구조적으로 복잡한 분기이며, 실패 시 사용자가 원하는 목적지에 도달하지 못해 이탈로 이어질 수 있음.
- **TC-WISHLIST-033 (선택 0건 상태 선택삭제 클릭 무반응 가드)**: Impact 2 / Likelihood 2 / Risk Score 4 — 버튼 클릭 시 아무 동작도 일어나지 않는(No-op) 가드 동작으로 데이터 변경이나 화면 전환이 발생하지 않아 영향 범위가 제한적임. 편집 모드 UI를 다루는 기존 유사 TC(TC-WISHLIST-020~023)와 동일한 Priority 수준으로 평가.
